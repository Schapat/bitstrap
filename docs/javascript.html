JavaScript

Rund 13 KB, keine Abhaengigkeiten. Alles laeuft ueber Attribute - JavaScript schreiben musst du nur, wenn du willst.

Steuerung per Attribut

Die Ereignisse haengen an document. Elemente, die du spaeter nachlaedst, funktionieren daher ohne erneutes init().

AttributWirkung
data-bit-toggle="modal"oeffnet das Ziel
data-bit-toggle="dropdown"klappt das Menue auf
data-bit-toggle="tab"wechselt den Reiter
data-bit-toggle="accordion"klappt den Abschnitt auf
data-bit-toggle="navbar"mobiles Menue
data-bit-toggle="theme"hell/dunkel umschalten
data-bit-target="#id"Ziel des Triggers
data-bit-dismiss="modal|alert|toast"schliesst das Umgebende
Klang beim Klick
data-bit-typewriterText erscheint zeichenweise
data-bit-singleAccordion: nur eines offen
data-bit-staticModal: nicht per Escape/Klick schliessbar

Modal

<button data-bit-toggle="modal" data-bit-target="#mein-modal">Oeffnen</button>

Oder aus dem Code heraus:

const m = Bitstrap.modal("#mein-modal");
m.show();
m.hide();
m.toggle();

Escape schliesst, ein Klick auf den Hintergrund ebenfalls, der Fokus wandert in den Dialog.

Ereignisse

document.querySelector("#mein-modal")
  .addEventListener("bit:modal:shown", () => {
    console.log("ist offen");
  });

Verfuegbar: bit:modal:show, bit:modal:shown, bit:modal:hide, bit:modal:hidden. Die show- und hide-Ereignisse lassen sich mit preventDefault() abbrechen.

Toasts

Bitstrap.toast({
  title:    "Item erhalten!",
  message:  "Ein Pixel-Schwert.",
  variant:  "success",      // success | warning | danger
  icon:     "sword",        // beliebiger Iconname
  position: "top-right",    // top-left | bottom-right | bottom-left | top-center
  timeout:  4000,           // 0 = bleibt stehen
  sound:    true
});

Typewriter

Der Text startet, sobald das Element ins Bild scrollt.

SYSTEM

Jedes Zeichen einzeln. Mit bleibt es still. 

<p data-bit-typewriter data-bit-speed="40">Text...</p>
Bitstrap.typewrite(document.querySelector("#dialog"));

Fortschritt setzen

Bitstrap.progress("#live-bar", 60);

Setzt zugleich aria-valuenow, damit Screenreader den Wert mitbekommen.

Ohne JavaScript

Layout, Grid, alle Formularelemente, Karten, Tabellen, Badges, Fortschrittsbalken, Dialogboxen und Tooltips funktionieren vollstaendig ohne die JS-Datei. Nur Modal, Tabs, Accordion, Dropdown, Toast, Typewriter und Sound brauchen sie.
