Formular-Widgets

Die Bausteine, an denen sich CSS-Frameworks sonst vorbeidruecken: Datumsauswahl, Autovervollstaendigung, Mehrfachauswahl.

Progressive Enhancement

Jedes Widget baut auf einem echten Formularelement auf. Ohne JavaScript bleibt ein normales Feld uebrig, das sich tippen, einfuegen und absenden laesst - der Kalender ist eine Zugabe, keine Voraussetzung.

Diese Seite braucht das Zusatzmodul: <script src="bitstrap-forms.js" defer></script>

Datepicker

Ein Attribut genuegt. Die Monats- und Wochentagsnamen kommen aus dem Browser und folgen der Sprache im <html lang>.

Format YYYY-MM-DD
Format TT.MM.JJJJ 
<div class="bit-datepicker">
  <input class="bit-input" type="text" data-bit-datepicker>
</div>

<!-- deutsches Format, Bereich begrenzen -->
<input class="bit-input" type="text"
       data-bit-datepicker data-bit-format="de"
       min="2026-01-01" max="2026-12-31">
Attribut / APIBedeutung
data-bit-format="de"TT.MM.JJJJ statt ISO
min / maxwaehlbarer Bereich (immer ISO)
bit:date:changeEreignis mit detail.date
Bitstrap.datepicker(sel)Instanz mit open/close/select

Tastatur: Alt+Pfeil runter oeffnet den Kalender, Esc schliesst ihn.

Combobox

Autovervollstaendigung mit Tastaturbedienung.

    <div class="bit-combobox">
  <input class="bit-input" type="text" data-bit-combobox
         data-bit-options='["Rot","Gruen","Blau"]'>
  <ul class="bit-combobox__list" role="listbox"></ul>
</div>

    Pfeil hoch/runter waehlt, Enter uebernimmt, Esc schliesst. Maus- und Tastaturauswahl sehen bewusst gleich aus.

    Tag-Eingabe

    Enter oder Komma fuegt hinzu, Backspace loescht das letzte. 
    <div class="bit-tags">
  <input type="hidden" name="tags" value="css,retro">
  <input class="bit-tags__input" type="text">
</div>

    Das versteckte Feld traegt die Werte kommagetrennt ins Formular - serverseitig kommt also ein ganz normaler Wert an.

    Validierung

    Bitstrap erfindet keine eigenen Regeln, sondern nutzt die Constraint-Validation des Browsers - required, type, pattern, minlength. Uebersetzt werden nur die Meldungen und Zustandsklassen. 

    <form data-bit-validate>
  <input class="bit-input" type="email" required
         data-bit-message="Eigene Fehlermeldung">
</form>

    Ein als fehlerhaft markiertes Feld wird beim Korrigieren sofort wieder freigegeben - nicht erst beim naechsten Absenden. Programmatisch: Bitstrap.validate(formElement).
