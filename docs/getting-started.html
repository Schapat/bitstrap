Installation

Bitstrap ist eine CSS-Datei und eine optionale JS-Datei. Mehr braucht es nicht.

Einbinden

Variante 1: Datei herunterladen

Die einfachste Variante. Beide Dateien aus dist/ neben deine Seite legen:

<link rel="stylesheet" href="bitstrap.min.css">
<script src="bitstrap.min.js" defer></script>

Variante 2: npm

npm install bitstrap

Danach im Projekt:

import "bitstrap/css";
import "bitstrap";

Variante 3: Quellen einzeln

Wer nur Teile braucht, bindet die Dateien aus src/ direkt ein. 00-tokens.css muss immer zuerst kommen, alles andere ist voneinander unabhaengig. 

@import "bitstrap/src/00-tokens.css";
@import "bitstrap/src/01-base.css";
@import "bitstrap/src/04-buttons.css";

Die Schrift

Bitstrap liefert bewusst keine Schriftdatei mit - das haelt das Paket klein und vermeidet Lizenzfragen. Ohne Pixelschrift faellt das Framework auf Monospace zurueck und funktioniert vollstaendig, sieht aber weniger nach 1988 aus.

Empfohlen ist Press Start 2P (SIL Open Font License):

<link href="https://fonts.googleapis.com/css2?family=Press+Start+2P&display=swap"
      rel="stylesheet">

Eine andere Schrift setzt du ueber eine einzige Variable:

:root {
  --bit-font: "Silkscreen", monospace;
}

Pixelschriften sind breit

Rechne mit etwa der doppelten Textbreite gegenueber einer normalen Schrift. Kurze Beschriftungen funktionieren, lange Fliesstexte werden schnell anstrengend - dafuer gibt es --bit-font-body, das du getrennt setzen kannst.

Erstes Beispiel

Eine vollstaendige Seite mit Bitstrap:

<!doctype html>
<html lang="de">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="bitstrap.min.css">
</head>
<body>
  <div class="bit-container bit-section">
    <h1>Hallo Welt</h1>
    <div class="bit-card bit-shadow">
      <div class="bit-card__body">
        <p>Das war es schon.</p>
        <button class="bit-btn bit-btn--primary">Start</button>
      </div>
    </div>
  </div>
  <script src="bitstrap.min.js" defer></script>
</body>
</html>

Das war es schon.

Namensschema

Alle Klassen beginnen mit bit-. Damit kollidiert Bitstrap mit keinem anderen Framework - du kannst es auch nur fuer einen Teilbereich einer bestehenden Seite einsetzen.

Wie das Pixel-Frame funktioniert

Die abgetreppten Ecken sind der Kern des Looks. Sie entstehen nicht durch Bilder, sondern durch vier versetzte Schatten - je einer pro Kante. Weil die Ecken dabei ausgespart bleiben, ergibt sich die typische 8-Bit-Silhouette: 

box-shadow:
  0  -4px 0 0 #1f1d36,   /* oben   */
  0   4px 0 0 #1f1d36,   /* unten  */
  -4px  0 0 0 #1f1d36,   /* links  */
   4px  0 0 0 #1f1d36;   /* rechts */

Jede Komponente steuert das ueber Variablen, du musst die Schatten also nie selbst schreiben:

VariableWirkung
--bit-fwRahmenstaerke
--bit-fcRahmenfarbe
--bit-fhlinnere Lichtkante oben
--bit-fshinnere Schattenkante unten
--bit-fdx/fdy/fdcversetzter Schlagschatten

Die Klasse .bit-frame macht jedes beliebige Element zur Pixel-Box:

Ein Rahmen.
Mit Schlagschatten.
Doppelt und farbig.

Browser-Unterstuetzung

Alle aktuellen Browser. Bitstrap nutzt Custom Properties, CSS Grid und mask-image - alles seit 2023 flaechendeckend verfuegbar. Ohne JavaScript funktionieren Layout, alle Komponenten und die Tooltips; nur Modal, Tabs, Accordion, Dropdown, Toast und Sound brauchen die JS-Datei.
