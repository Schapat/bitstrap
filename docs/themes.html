Dark Mode

Bitstrap folgt automatisch der Systemeinstellung. Eine bewusste Wahl setzt du per Attribut auf <html>: 

<html data-bit-theme="dark">
<html data-bit-theme="light">

Der Umschalter braucht nur ein Attribut - das JS erledigt den Rest samt Speicherung:

<button class="bit-btn" data-bit-toggle="theme">Umschalten</button>

Oder programmatisch:

Bitstrap.theme.toggle();
Bitstrap.theme.set("dark");
Bitstrap.theme.get();

Eigenes Theme

Ein Theme besteht aus semantischen Tokens. Diese hier reichen fuer ein vollstaendiges Erscheinungsbild: 

.bit-theme-meins {
  /* Flaechen und Text */
  --bit-bg:          #1a1c2c;
  --bit-surface:     #29366f;
  --bit-surface-alt: #3b5dc9;
  --bit-text:        #f4f4f4;
  --bit-muted:       #94b0c2;
  --bit-border:      #f4f4f4;
  --bit-shadow-c:    rgba(0,0,0,.5);
  --bit-focus:       #ffcd75;
  --bit-overlay:     rgba(26,28,44,.85);

  /* Bedeutungen - jeweils Farbe + Vordergrund */
  --bit-primary:    #ef7d57;  --bit-primary-fg:  #1a1c2c;
  --bit-secondary:  #3b5dc9;  --bit-secondary-fg:#f4f4f4;
  --bit-success:    #a7f070;  --bit-success-fg:  #1a1c2c;
  --bit-warning:    #ffcd75;  --bit-warning-fg:  #1a1c2c;
  --bit-danger:     #b13e53;  --bit-danger-fg:   #f4f4f4;
  --bit-info:       #41a6f6;  --bit-info-fg:     #1a1c2c;
  --bit-dark:       #1a1c2c;  --bit-dark-fg:     #f4f4f4;
  --bit-light:      #566c86;  --bit-light-fg:    #f4f4f4;
}

Kontrast pruefen

Retro-Paletten sind oft grell und liegen im Kontrast dicht beieinander. Pruefe jedes *-fg-Paar auf mindestens 4,5:1 gegenueber seiner Flaeche - sonst wird die Optik auf Kosten der Lesbarkeit erkauft.
