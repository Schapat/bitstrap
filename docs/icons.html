Eigene Icons

Icons entstehen in build/icons.mjs als Zeichenraster. Ein neues Icon ist acht Zeilen Text - der Build erzeugt daraus die CSS-Regel: 

// build/icons.mjs
export const ICONS = {
  krone: [
    "........",
    "#..##..#",
    "#.####.#",
    "########",
    "########",
    ".######.",
    "........",
    "........",
  ],
};

Danach neu bauen:

node build/build.mjs

Und benutzen als .bit-icon--krone. Die Pfeil-Icons werden uebrigens aus einem einzigen Raster erzeugt und dreimal gedreht - dieselbe Technik steht dir offen.

Wie es funktioniert

Jedes Raster wird zu einem SVG, in dem zusammenhaengende Pixel einer Zeile zu einem Rechteck verschmelzen. Aus 64 Einzelpixeln werden so meist unter 14 Rechtecke. Das SVG landet als Data-URI in einer CSS-Maske: 

.bit-icon--heart {
  mask-image: url("data:image/svg+xml,...");
}
.bit-icon {
  background-color: currentColor;
  mask-size: 100% 100%;
}

Die Maske bestimmt die Form, die Hintergrundfarbe die Farbe. Daher faerbt color das Icon - und es gibt weder Schriftdatei noch Sprite-Sheet noch einen zusaetzlichen Request.
